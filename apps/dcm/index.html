What the app does 这个 App 能做什么

  • Local only. Files are parsed and rendered on the device. There is no network permission, no backend, no account, no ads, no tracking, no analytics.
  • Series grouping. Imported files are grouped by SeriesInstanceUID, so one study shows up as its series.
  • Multi-frame and multi-layer. A series can be browsed slice by slice; a multi-frame instance can be stepped frame by frame.
  • Display controls. Window width / window level, invert, reset, plus pinch-zoom and pan.
  • Full tag table. All DICOM data elements are listed, with the file’s declared character set decoded (including Chinese, e.g. ISO 2022 IR 58 / GB18030).
  • PNG export. The currently displayed image can be exported through the iOS share sheet.
  • Platform. iPhone only, iOS 16.0 or later.

纯本地。文件在设备本地解析与渲染：没有联网权限、没有后端、没有账号、无广告、无追踪、无统计。
序列归组。导入的文件按 SeriesInstanceUID 归组成序列。
多帧与多层。序列可逐层浏览；多帧实例可逐帧翻阅。
显示控制。窗宽/窗位调节、反色、复位，以及双指缩放与平移。
全部标签。列出 DICOM 的全部数据元素，并按文件声明的字符集解码（含中文，例如 ISO 2022 IR 58 / GB18030）。
导出 PNG。可通过系统分享面板导出当前显示图像。
平台。仅支持 iPhone，iOS 16.0 起。

How to import 如何导入

  1. Get the .dcm files onto the iPhone first — for example save them from Mail, from a chat app, or from your computer to the Files app. If they came in an archive, unzip it in Files first.
  2. In the app, tap the import button in the top bar. The system file picker opens.
  3. Select individual .dcm files, or select a folder that contains DICOM files. Everything you pick is copied into the app’s own sandbox; the originals in Files are never moved, changed or deleted.
  4. The library lists one row per series, with the patient name, series description and frame count read from the file.

If a file cannot be parsed it is skipped and the app reports how many were skipped. Files that are not DICOM (for example a plain .zip, .jpg or .txt) will not open.

1. 先把 .dcm 文件放进 iPhone：例如从邮件、聊天工具保存到「文件」App，或从电脑传到「文件」App。如果是压缩包，先在「文件」App 里解压。
2. 在 App 顶部点击导入按钮，打开系统文件选择器。
3. 选择若干个 .dcm 文件，或直接选择一个包含 DICOM 的文件夹。所选内容会被复制进 App 自己的沙盒； 「文件」里的原件不会被移动、修改或删除。
4. 图库按序列列出，每行显示从文件里读到的患者姓名、序列描述与帧数。

无法解析的文件会被跳过，App 会提示被跳过的数量。非 DICOM 文件（例如 .zip、.jpg、.txt）无法打开。

Window width and level 窗宽 / 窗位怎么用

A DICOM pixel is a raw number, so the app maps a slice of those numbers to black-and-white: the window level is the centre value that lands on mid-grey, and the window width is how wide a range of values that spread covers. A narrow width gives high contrast (fewer shades, harder edges); a wide width shows more tissue at once but looks flatter.

  • The top-left overlay shows the current W (width), L (level) and the displayed range.
  • Tap Window in the control bar, then drag on the image: left-right changes the width, up-down changes the level. Values update live.
  • Tap Pan to switch the drag to moving the image instead.
  • Invert flips black and white. Reset — in the control bar, and also in the ⋯ menu — restores the window and the zoom/pan.
  • When a file opens, the app starts from the window values stored inside the file when it has them.

DICOM 像素是原始数值，App 把其中一段数值映射成黑到白：窗位决定哪个数值落在中间灰度， 窗宽决定这段映射覆盖多宽的数值范围。窗宽越窄对比度越高（灰阶少、边缘硬）；窗宽越宽同时可见的组织更多，但画面更平。

  • 画面左上角实时显示当前 W（窗宽）、L（窗位）与显示范围。
  • 在控制条点「窗宽窗位」，然后在画面上拖动：左右拖动改窗宽，上下拖动改窗位，数值实时更新。
  • 点「平移」后，拖动就变成移动图像。
  • 「反色」交换黑白；「复位」在控制条和 ⋯ 菜单里都有，可恢复窗口设置与缩放平移。
  • 如果文件本身带有窗口参数，打开时会以文件里的值作为初始显示。

Slices, frames, zoom 多层浏览、多帧浏览与缩放

  • Slices. The thumbnail strip at the bottom is the whole series — tap any thumbnail to jump to that layer. The current layer is highlighted.
  • Frames. If the current instance holds several frames, a slider appears above the strip and the overlay shows Frame n/N; drag the slider to flip frames one by one.
  • Zoom. Pinch to zoom between 0.5× and 12×. The image is shown with nearest-neighbour scaling, so pixels stay crisp instead of being smoothed.
  • Pan. Switch to Pan mode and drag to move the image; Reset puts it back.

逐层。底部缩略图条就是整个序列，点任意缩略图即可跳到该层，当前层有描边高亮。
多帧。当前实例含多帧时，缩略图上方会出现滑杆，左上角显示「帧 n/N」；拖动滑杆即可逐帧翻阅。
缩放。双指缩放范围 0.5×–12×，采用最近邻放大，保持像素锐利而不是糊成一片。
平移。切到「平移」模式后拖动即可移动图像，「复位」可还原。

DICOM tags 查看 DICOM 数据元素（标签表）

Open the ⋯ menu and tap DICOM Tags. Key information (patient name and ID, study date, modality, body part, transfer syntax, dimensions, bit depth, rescale, window) is shown first; below it you can expand the full list of data elements in the file, including sequences and their item counts.

Text is decoded with the character set declared inside the file, so Chinese names and descriptions from Chinese hospital equipment display correctly. Nothing inside the file is ever translated — patient names, series descriptions and every other value are shown exactly as recorded. Translating medical data would change its meaning.

点右上角 ⋯ 菜单里的「DICOM 标签」即可查看。先显示关键信息（患者姓名与编号、检查日期、检查方式、部位、 传输语法、尺寸、位深、灰度变换、窗口参数），其下可以展开文件里的全部数据元素，包括序列及其项数。

文本按文件内声明的字符集解码，因此中国医院设备里的中文姓名、中文描述都能正确显示。文件内的数据永不翻译—— 患者姓名、序列描述等所有值都按原始记录原样呈现，因为翻译医学数据会改变它的含义。

Export PNG and its limits 导出 PNG 与它的限制

Tap ⋯ → Export displayed image (PNG) (or the share button in the control bar). The system share sheet opens, where you can save the image to your Photo Library or send it anywhere you like. Nothing is uploaded by the app itself.

  • The PNG is an 8-bit display image produced with the window width / level, invert and zoom you have on screen at that moment — not the original pixel data.
  • It carries no DICOM metadata and cannot be opened again as a DICOM file.
  • Because it is a display result, it is not suitable as a clinical or diagnostic reference. Keep the original .dcm files if you need the real data.

点 ⋯ →「导出当前显示图 (PNG)」（或用控制条上的分享按钮），会打开系统分享面板， 可以存到照片 App 或自行转发。App 本身不会上传任何东西。

  • 导出的 PNG 是按当时屏幕上的窗宽窗位、反色与缩放生成的 8 位显示图像，不是原始像素数据。
  • 它不携带任何 DICOM 元数据，也无法再作为 DICOM 文件打开。
  • 它是显示结果，不能作为临床或诊断依据。需要真实数据时请保留原始 .dcm 文件。

Supported transfer syntaxes 支持的传输语法

Supported:

  • Explicit VR Little Endian
  • Implicit VR Little Endian
  • Deflated Explicit VR Little Endian
  • RLE Lossless
  • JPEG Baseline (Process 1)
  • JPEG 2000, including lossless profiles
  • Explicit VR Big Endian

Anything else — for example encrypted DICOM or other JPEG profiles — is reported as “Cannot decode this file”. The transfer syntax of an opened file is listed in the tag table, so you can check it there.

以上即为当前支持的全部传输语法。

其他语法（例如加密 DICOM、或其他 JPEG 配置）会提示「无法解码该文件」。已打开文件的传输语法可以在标签表里查到。

Languages 支持的语言

The interface is available in English (default) and Simplified Chinese. The app follows your system language; you can also set it per-app in iOS Settings → DICOM Viewer → Language. Data read from DICOM files (patient names, series descriptions, and so on) is never translated in either language.

界面提供英文（默认）与简体中文两种语言，会跟随系统语言； 也可以在 iOS「设置 → DICOM 影像 → 语言」里单独为本 App 指定。无论哪种界面语言，DICOM 文件内的数据（患者姓名、序列描述等）都不会被翻译。

Frequently asked questions 常见问题

A file will not open. What should I check? 文件打不开，应该先检查什么？

Check the transfer syntax against the list above. Then make sure the file is a real DICOM file and was downloaded completely — a truncated download (a few hundred KB instead of several MB) is the most common cause. If it came from an archive, unzip it first. There is no built-in viewer for non-DICOM formats.

先对照上面的列表确认传输语法是否受支持；再确认它确实是 DICOM 文件且下载完整——下载中断（只有几百 KB 而不是几 MB）是最常见的原因。 来自压缩包请先解压。本 App 不提供非 DICOM 格式的查看功能。

It looks different from the film I was given at the hospital. 为什么和医院给我的那张胶片/图像看起来不一样？

Usually window settings and the display itself. The hospital film was printed with its own window settings on a calibrated medical monitor; here the mapping is recomputed from the window width / level you set, on a phone screen that is not calibrated for medical use. Adjust the window, try Invert, and compare layers. This is exactly why the app must not be used as a clinical reference.

通常是窗口参数和显示设备不同造成的。医院的胶片是在校准入过的医用显示器上、按它自己的窗口参数输出的； 这里则由你设置的窗宽窗位实时换算，而且手机屏幕并未经过医学用途的显示校准。可以调整窗宽窗位、试试「反色」、并对照相邻层比较。 这正说明本 App 的显示结果不能作为临床依据。

Where do my images live, and how do I delete them? 我的影像存在哪里？怎么删除？

Copied files live only inside this app’s sandbox on your device; the library footer shows how many files are stored. To remove one series, delete it from the library; to remove everything, use Delete all images (清空全部影像). Deleting the app removes its sandbox entirely. No copy exists anywhere else, because the app never transmits anything.

导入的文件只存放在本 App 于本机的沙盒内，图库底部会显示当前文件数量。删除单个序列可在图库里直接删除； 要一次清空就用「清空全部影像」。卸载 App 会连同沙盒一起删除。别处不存在任何副本，因为 App 从不外传数据。

Does the app upload my images or read my photo library? App 会上传我的影像，或读取我的相册吗？

No. The app has no network permission, so it cannot reach the internet at all, and it does not ask for Photo Library access. It can only read the files you actively choose in the file picker, and it can hand you a PNG through the system share sheet, which you drive yourself.

不会。App 没有联网权限，根本无法访问网络，也不会申请相册权限。它只能读取你在文件选择器里主动选择的文件； 导出 PNG 走系统分享面板，完全由你自己操作。

The patient name shows as strange symbols. 患者姓名显示成乱码/奇怪符号。

The app decodes the character set declared in the file, including Chinese sets such as ISO 2022 IR 58 (GB18030 / GBK / GB2312) and UTF-8. Some older files do not declare a character set at all; in that case the app makes a best guess, which can be wrong for a name. The pixel data is not affected. If you send us a description of such a file (never the image itself), we can look into it.

App 按文件声明的字符集解码，支持中文常用的 ISO 2022 IR 58（GB18030 / GBK / GB2312）以及 UTF-8。 少数老文件完全没有声明字符集，此时只能按经验推测，姓名字段就可能猜错。像素数据不受影响。如果你能描述这类文件的情况（请不要发影像本身），我们可以进一步排查。

Does it work on iPad or Mac? 支持 iPad 或 Mac 吗？

No. Version 1.0 is iPhone-only and requires iOS 16.0 or later.

不支持。1.0 版本仅支持 iPhone，需要 iOS 16.0 或更高版本。

Can I use this to review my own scan at home? 我能在家里看自己的片子吗？

You can look at them, and read the tag values, for your own understanding. What you must not do is treat what this app shows as a diagnosis. Second opinions, treatment choices and any follow-up belong to a qualified professional working from the original data and the formal report.

你可以为了自己理解而查看影像、读取标签数值。但不能把本 App 显示的内容当成诊断结论。 第二意见、治疗选择和随访都必须由具备资质的医务人员依据原始数据与正式报告做出。
